# Mote Cottage Studio

A cozy art cottage: draw, watercolour and paint together in co-op. Part of the **Mote** charms, small web toys for testing ideas for Mote, a small, nicotine-free glowing companion you can hold.

Live at: https://charmnomicon.com/a/mote-cottage-studio

## Files

- `index.html`: the whole app (HTML, CSS and JS in one file).

Outside Charmnomicon it runs in preview mode with in-memory data.
